# Working Rules

- **Change only what's explicitly asked.** Do the specific task requested and nothing more.
- **Never restructure or rewrite code or content beyond the specific request.** No opportunistic refactors, renames, reformatting, or "improvements" to surrounding code or copy.
- **Ask before assuming a broader scope.** If a request seems to imply changes beyond what was literally asked, confirm with the user first.
- **Don't touch files that aren't necessary for the task.** Leave unrelated files untouched.
- **Show proposed copy/wording changes before writing them.** Present the exact new text for approval first, then write it to the file only after confirmation.
